## 📖 Overview

The **Dynamic Traffic Management System** explores an adaptive approach to managing traffic at intersections.

The project focuses on using traffic-condition information to support signal-timing decisions. Its aim is to allocate green time according to traffic demand, reduce unnecessary waiting, and improve the use of available road capacity.

## 🎯 Objectives

- Reduce unnecessary waiting time at traffic signals.
- Improve traffic movement through intersections.
- Adapt signal decisions to changing traffic demand.
- Address congestion caused by uneven vehicle distribution.
- Evaluate the effectiveness of dynamic traffic-control strategies.

## ⚙️ System Workflow

The intended operating cycle consists of four stages:

1. **Collect traffic information**  
   Obtain traffic data from the input source used by the project.

2. **Analyze traffic conditions**  
   Assess the demand or congestion level for each monitored direction.

3. **Determine signal timing**  
   Apply the control logic to decide signal priority and green-light duration.

4. **Update and repeat**  
   Apply the next signal state and reassess conditions during subsequent cycles.

## 📊 Evaluation

Useful measures for evaluating the system include:

- **Average waiting time** — Time vehicles spend waiting at an intersection.
- **Queue length** — Number of vehicles waiting in each direction.
- **Traffic throughput** — Vehicles passing through the intersection over a defined period.
- **Signal allocation** — How green time is distributed across competing directions.
